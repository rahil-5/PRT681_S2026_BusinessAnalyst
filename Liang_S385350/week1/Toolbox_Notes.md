# Toolbox Notes — Tool Auditions

Treating each new tool like a job audition: what's it for, would I
hire it again, and what's it bad at. Tried each one against my cinema
booking case study.

## Jira

- **What it's for:** Tracking backlog items/tickets for a delivery team
- **What I tried:** Set up a sample backlog for the cinema project
  (e.g. "As a user, I want to see real-time seat availability")
- **Would hire again?** Yes — good for tracking status, less good for
  actual requirement detail (needs Confluence alongside it)

## Confluence

- **What it's for:** Longer-form documentation linked to Jira tickets
- **What I tried:** Drafted a short requirements page for the seat-
  hold/expiry feature
- **Would hire again?** Yes, for anything that needs more context than
  a ticket title

## Lucidchart / Miro

- **What it's for:** Process diagrams and workshop boards
- **What I tried:** Drew a simple flow of the booking process (browse →
  select seats → checkout → confirmation)
- **Would hire again?** Yes for diagrams; Miro specifically better for
  live brainstorming than for a "finished" document

## Excel / Google Sheets

- **What it's for:** Quick data checks, simple models
- **What I tried:** A small mock dataset of bookings to practise
  filtering/pivoting

## Power BI

- **What it's for:** Turning raw data (like bookings, seat occupancy,
  revenue by showtime) into dashboards stakeholders can actually read
- **What I tried:** Explored how a simple dashboard could show
  occupancy rate by showtime and cancellations over time for the
  cinema case study
- **Would hire again?** Yes — this is the tool that turns "I ran a
  query" into something a non-technical stakeholder can act on

## Quick reference — when I'd reach for which tool

| Situation | Tool I'd pick | Why |
|-----------|---------------|-----|
| Need alignment fast across 5 people | Miro | Live, visual, collaborative |
| Need a permanent record of a decision | Confluence | Searchable, linked to tickets |
| Need to check a claim against real numbers | Excel or SQL | Fast, no dashboard overhead needed |
| Need to show trends to stakeholders repeatedly | Power BI | Refreshable dashboard beats a static report |
